הבוט של אתר הפניקס — Workflow

LlamaIndex Workflow מונחה-אירועים: אימות → הבנת השאלה → גבולות → ניתוב → חיפוש סמנטי / שליפה מובנית → אימות ציטוט

flowchart TD
  S([StartEvent: question + history]) --> V[validate_input]
  V -- empty / too long --> X1([Stop: ask again])
  V -- CondenseEvent --> C[condense
Haiku, only if history]
  C -- ClassifyEvent --> U{{"understand — in parallel:
classify (Haiku) · route (LLMSingleSelector)
· retrieve (Pinecone top-25 + Cohere rerank)"}}
  U -- advice --> X2([Stop: no personal advice + referral])
  U -- off_topic --> X3([Stop: only fnx.co.il topics])
  U -- StructuredEvent --> ST[structured_lookup
LLM builds query on structured.json]
  ST -- "nothing found:
prefetched evidence" --> EV
  ST -- VerifyEvent --> VF
  U -- EvaluateEvent --> EV{evaluate}
  RE[retrieve
Pinecone + rerank] -- EvaluateEvent --> EV
  EV -- "no evidence,
attempts < 2" --> RW[rewrite
Haiku: site terminology]
  RW -- RetrieveEvent --> RE
  EV -- "no evidence,
attempts = 2" --> X4([Stop: not on the site
no answer-LLM call])
  EV -- SynthesizeEvent --> SY[synthesize
Claude Sonnet, strict prompt
streams TokenEvent to the UI]
  SY -- VerifyEvent --> VF[verify
cited URLs ⊆ evidence URLs]
  VF --> OUT([Stop: answer + source URL
+ referral if personal policy])
StepLLM?מה הוא עושה
validate_inputלאקלט ריק/ארוך מדי. שומר ב-State את השאלה ומאפס attempts.
condenseHaiku, רק בשאלת המשך"ותוך כמה זמן?" → שאלה עצמאית לפי ההיסטוריה.
understandHaiku ×2 + Cohereשלוש פעולות במקביל (חיסכון בזמן): סיווג site_question / personal_policy / advice / off_topic (גבולות הבוט), ניתוב סמנטי/מובנה, ואחזור סמנטי. אם השאלה נעצרת או הולכת לשכבה המובנית — האחזור פשוט לא בשימוש.
structured_lookupHaiku + Sonnetשאילתה לפי הסכמה → סינון בפייתון → ניסוח מהפריטים. אין תוצאות → חזרה לחיפוש סמנטי.
retrieveלא (Cohere)Embedding לשאלה, Pinecone, סינון ציון, rerank.
evaluateלאיש ראיות? אם לא — ניסוח מחדש פעם אחת, ואז "לא מופיע באתר".
synthesizeSonnetתשובה רק מהקטעים, 2–4 משפטים בעברית, "המקור:". הטקסט נשלח לממשק תוך כדי כתיבה (streaming); אחרי verify הוא מוחלף בגרסה המאומתת.
verifyלאמוחק כתובות שלא הגיעו מהראיות, מוסיף מקור אם חסר, מוסיף הפניה לפוליסה אישית.
